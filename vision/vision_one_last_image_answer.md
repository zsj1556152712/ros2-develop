# 视觉任务：One Last Image 实现原理推测（文字回答）

## 这个工具在做什么

One Last Image（"One Last Kiss 风格封面生成器"）把上传的照片/截图处理成**赛璐珞（Cel）动画风格**：画面变成大块平涂色 + 清晰深色描边，类似《新·福音战士剧场版》那种手绘动画质感。界面上的两个可调参数是**线迹轻重**和**调子数量**，并有降噪、水印等处理。

赛璐珞动画和真实照片的本质区别有两点：① 物体表面是**有限的几块平涂色**（高光、中间调、阴影），没有照片里连续的明暗渐变和噪点；② 物体轮廓有**深色描边线**。所以整个处理就是围绕"磨平色块、提取线条、压缩色阶"三件事展开。

## 推测的实现步骤（经典 OpenCV 卡通化流程）

### 1. 保边降噪（磨平色块）

先用**双边滤波（Bilateral Filter）**（或引导滤波、表面模糊 Surface Blur）对图像做平滑。

为什么不用普通的高斯模糊：高斯模糊会把边缘和色块一起糊掉；而双边滤波同时考虑"空间距离"和"像素亮度差"——色块内部亮度接近，会被强力平均，噪点和压缩伪影被磨平；边缘两侧亮度差异大，滤波自动减弱，**轮廓线得以保留**。这正好符合"平涂色块 + 清晰边界"的需求。通常会连续做几次双边滤波加强效果。

### 2. 线迹提取（边缘检测 + 描边）

对应"**线迹轻重**"参数：

- 把图像转成灰度图，用 **Canny 边缘检测**（或 Sobel / Laplacian、自适应阈值）找出物体轮廓，得到一张黑白线稿（边缘为黑、其余为白）；
- "线迹轻重"控制 Canny 的阈值或描边粗细——值越大，检测越敏感、线条越粗越深；
- 最后把这层深色线稿叠加（乘法/按位与）到处理好的色块画面上，形成手绘描边效果。

### 3. 调子数量（色调分离 / 色彩量化）

对应"**调子数量**"参数，这是形成"平涂感"的关键：

- 真实照片的明暗是连续的，而赛璐珞每个区域只有几级明暗。把图像转换到 HSV 或 Lab 颜色空间，对明度（或各通道）做**色阶量化（Posterization，色调分离）**：把连续值按"调子数量"划分成若干区间，同一区间内的像素强制取同一个值，连续渐变就被压成了一级一级的硬边色块；
- "调子数量"就是分级的数量——值越小色块越少、越卡通化；值越大越接近原图；
- 也可能用 **K-means 色彩聚类**实现：把全图像素聚成 K 个代表色，每类像素替换成聚类中心色，效果同样是有限色数的平涂。

### 4. 合成与收尾

- 将"量化后的平涂色层"与"深色线稿层"叠加，得到最终的赛璐珞画面；
- 可能再做一次整体调色（复古/电影感色调）、对比度增强，以及界面提到的水印处理（添加或去除 Kiss 相关水印）。

## 一句话总结

> 它本质是一条 **「双边滤波保边降噪 → Canny 提取轮廓线稿 → 明度/色彩量化做色调分离 → 线稿与平涂色层叠加」** 的卡通化（Cartoon Filter）流水线，"线迹轻重"调描边强度，"调子数量"调色阶分级数。这与 OpenCV 官方教程中的图像卡通化例程思路一致。
